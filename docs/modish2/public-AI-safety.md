# Публичный выпуск: необязательная AI-визуализация

Публичный доступ снимает белый список через `CLOSED_ALPHA_ENABLED=false`.
Аутентификация личной ленты, профиля, отдельного каталога и Intent остаётся.
Это решение не разрешает автоматически включать платные дополнительные функции.

`POST /visual-analysis` использовал существующий analysis и запускал image
provider без отдельной durable-квоты, резервирования стоимости или idempotent
replay. Обычный лимит запросов на IP не является бюджетом AI-провайдера.
Наличие прежнего анализа, действующей trial или ограниченного photo ledger
не ограничивало количество последующих генераций изображений.

Добавлен `STYLE_VISUAL_ENABLED=false` по умолчанию. Только явное `true`/`1`
(без учёта регистра и внешних пробелов) включает прежнюю генерацию. Пустое,
неизвестное или ошибочное значение оставляет её выключенной.

При выключенной функции запрос возвращает HTTP503 и `Cache-Control: no-store`:

```json
{"detail":"Визуализация стиля пока недоступна. Продолжите подбор вещей."}
```

Отказ происходит до чтения snapshot и вызова provider, в том числе для прежних
клиентов и аккаунтов с уже сохранённым analysis. Это общий feature gate, поэтому
при выключенной функции ответ503 одинаков и без bearer token; данные аккаунта
не читаются. При явном включении сохраняются401 для неверного/отсутствующего
токена,400 при отсутствии analysis и прежние200/502 для provider результата.

Общий onboarding capability helper добавляет `style_visual_v1` в существующий
`recommendation_features` только при включении. Status, preferences и WOW
используют один helper. Клиент не отправляет запрос, если признака нет.
Признак означает включённую сервером возможность, а не новую квоту или
гарантированную возможность оплаты. Для текущего публичного выпуска функция
должна оставаться выключенной до отдельного решения о лимитах и стоимости.

Опциональная генерация не нужна для Style Swipe, WOW из реальных SKU, ленты,
поиска и сохранений. Photo analysis reservation ledger не менялся.
Флаг не переключается автоматически при выборе public/alpha: публичная
конфигурация проверяется отдельно. Изменение deployment environment обычно
требует перезапуска процесса; слежение за `.env` не добавлялось.

Это минимальная блокировка расходов, не реализация AI billing/quota. Явное
включение возвращает прежний unmetered provider path и требует осознанного
операторского решения. Реальные секреты, настройки сервера, AI-вызовы,
deployment и рабочие данные при разработке не использовались.
