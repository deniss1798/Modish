# Modish: состояние разработки на 13 октября 2026

Этот отчёт фиксирует актуальный код для GitHub. Рабочий API и APK остаются build13; новые проверки выполнены локально и на изолированной серверной копии. Обновление GitHub не является обновлением production.

## Исправлено

- Жизненный цикл сессии: ответы и запросы прежнего аккаунта отменяются, навигация очищается при выходе/истечении сессии. Обычная ротация токена сохраняет открытый экран. Записи токенов и удаление сериализованы; собственный HTTP transport закрывается.
- Защищены авторизация после смены поколения, совместное использование внедрённого API и аналитика отложенного перехода в магазин.
- Размер проверяется по лёгкой проекции до загрузки полного товара. Порядок, поздние кандидаты, состояние ORM и все проверки допуска сохранены; пагинация применяется один раз, курсоры закрываются.
- Ограничены память и срок хранения IP в rate limiter. Некорректный URL исторической карточки не обрушает выдачу; общий допуск отклоняет непубличные фото. Представитель дублей Intent выбирается в стабильном порядке.
- Нижние действия учитывают системную панель Android. Исправлены пустая лента при увеличенном тексте, перегруженные действия образа и расположение результатов запроса. Убрано неподтверждённое обещание трёх комплектов после фото.
- Выбор бренда открывает поиск, дополнения в деталях открывают нужный товар. Обработаны переходы после закрытия экрана и ошибки сети без технических инструкций пользователю.
- Общая тема выделена из контроллера и переиспользуется. Inter и Playfair Display включены локально с неизменёнными бинарниками, OFL-лицензиями и исходной ревизией; тесты загружают эти же шрифты.

## Скорость на реальном тестовом каталоге

Три завершённые сессии для одного контролируемого LETTER L-профиля, по 15 реальных реакций (10 лайков / 5 отказов). Обе ревизии использовали один актуальный момент времени и один каталог. Все ordered hashes колоды и первой ленты совпали; каждый возвращённый товар прошёл exact-size/fresh-stock проверку.

Это контрольное измерение на контейнере 0,75 CPU, не production p95 и не нагрузочный тест. WOW вернул 0 образов в обеих ревизиях, поэтому ускорение не считается выполнением требования к полным образам.

## Остаётся в работе

Пользователь разрешил отдельный каталог с пометкой «размер не проверен». Это следующая задача: доступ к одежде/обуви без обещания соответствия размера, отдельно от строгой персональной ленты/WOW. На момент этого GitHub-снимка новый каталог ещё не реализован.

Также ревизия выявила гонку квоты фото и транзакции через внешние `await`, а также длительную блокировку владельца при ранжировании. Их конкретные контракты и проверки PostgreSQL описаны в [архитектурном аудите](backend-engineering-audit-20261013.md). Исправление этих пунктов, согласованный выпуск API/клиента и новый APK ещё не завершены.

Последнее обновление четырёх разрешённых фидов завершилось на изолированной копии; товарные ID сохранены. Проверка десяти профилей по-прежнему не подтверждает системы размеров обуви и достаточное покрытие полных образов. Производственный импорт не выполнялся.
