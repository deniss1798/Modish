# Modish: build 6, исправления и обновление интерфейса

Сервер обновлён: 2026-09-16T04:42:16.211062+00:00 (UTC).

## Изменения

- В ленту и подборки допускаются одежда и обувь. Товары для дома, посуда, косметика и неизвестные типы товаров отсеиваются; детские товары по-прежнему исключены.
- Сессия продлевается автоматически после истечения access-токена. На устройстве пара токенов хранится в защищённом хранилище; на сервере хранится только хеш refresh-токена. Срок сессии — 90 дней; выход отзывает возможность продления.
- Несколько одновременных ответов 401 используют один запрос продления. Сбой сети при продлении не удаляет сессию. Вход и регистрация отправляются без старого токена.
- Лента начинает подгрузку заранее, сохраняет текущую карточку и непросмотренную очередь, исключает уже смахнутые товары даже до завершения записи события. Поздние ответы прежних фильтров игнорируются.
- Пока идёт подгрузка, показан статус поиска следующих вещей вместо ошибочного сообщения об исчерпании каталога.
- Обновлены карточки, кнопки, навигация и логотип в прежней чёрно-золотой палитре. Фото сохраняет полное изображение товара. Убраны лишние подписи, цена в рублях обозначается ₽.
- Заменены иконка приложения, логотип и полноэкранный стартовый фон на изображения пользователя. На небольших экранах вступительный текст не перекрывает логотип.
