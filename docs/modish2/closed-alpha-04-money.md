# 0.4 — единый контракт цен

15 октября 2026. Только код и изолированные проверки; рабочая база, API и APK
не изменялись.

## Контракт

Все цены хранятся в рублях: `NUMERIC(14,2)` в БД, `Decimal` в backend.
JSON также содержит рубли: целое число для целой суммы, число с дробной частью
для копеек. Умножения на 100 при обмене нет. Существующие целые цены сохраняют
значение и формат API. Ввод бюджета остаётся в целых рублях.

Один парсер обслуживает фиды, нормализацию, ручной импорт и admin API.
Поддерживает числовые типы, точку/запятую, проверенные разделители тысяч,
валютный суффикс и научную запись. Округление до копейки — один раз, half up.
Отрицательные, bool, нечисловые, бесконечные, слишком длинные и выходящие за
лимит значения отвергаются. Максимальная цена товара — 10 000 000 рублей.
Неоднозначные/некорректные группировки не угадываются.

Фильтры сравнивают полную цену: 10 000,99 не проходит лимит 10 000.
Суммы образов, скидки, события, исторические границы цен, кеши и сценарий
«показать дешевле» также сохраняют копейки. Существующие правила бюджета
на вещь/комплект и допуск engine v2 в этом блоке не переопределялись;
сквозная честность WOW проверяется отдельно в 1.4.

Flutter сохраняет дробную цену и единообразно отображает `1299,50`
и целые суммы без `,00`. Область цены
переносится на следующую строку при узком экране/увеличенном шрифте.

## Миграция

Alembic `0026` переводит price/old_price товаров и total_price образов из Integer
в Numeric без пересчёта единицы. ID, связи и старые целые значения сохраняются.
Для SQLite используется отдельное migration connection с выключенным FK;
включённый FK вызывает отказ до изменения схемы. Обратная миграция заранее
проверяет все три поля и отказывается терять копейки либо переполнять Integer.

Ранее потерянные копейки не восстанавливаются из округлённого числа. Версия
нормализации повышена до v7: повторная обработка имеющихся raw records может
вернуть исходную точность, сохраняя ID и наблюдения наличия. Это проверено
на изолированных данных, но не запускалось в рабочей базе.
