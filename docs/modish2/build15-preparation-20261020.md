# Build15 — подготовка после локальной приёмки

Состояние на 20 октября 2026, московское время. Продолжение после вопроса
об обновлении сервера и готовности к выпуску. Эта запись не означает деплой.

## Что подготовлено

- Версии согласованы: Flutter `1.0.1+15`, API `1.0.1-build15`.
- [Пакетирование](build15-package.md) фиксирует полный Git-коммит, SHA256
  исходников и архива. Отдельный checker проверяет архив до исполнения
  и запускает backend из новой изолированной копии.
- [Реальные миграции](build15-migrations.md) проверены на одноразовом
  PostgreSQL: семь сценариев, включая lossless rollback и атомарный отказ
  при несовместимых данных. Это не копия рабочей БД.
- [Подпись Android](build15-android-signing.md): release требует внешнюю
  конфигурацию, автоматическая подмена на debug-подпись удалена.
- [Ограничения деплоя](build15-deployment-safety.md): обычная пересборка
  старого Compose и возврат старого API после новых записей не считаются
  проверенным сценарием обновления/отката.

SSH `root@194.87.118.236` отклонил сохранённый ключ и один ввод ранее
переданного пароля. Пароль не записывался в файлы или журналы; повторные

Для следующего шага нужны актуальный доступ и проверка пакета на новой
копии рабочей БД. Включение обновления требует конкретного согласования
deployment scope: в ТЗ от 13 октября production deployment был исключён.
Также запрошены канал выпуска и политика доступа участников; реальные
email/инвайты пока не настроены. Публичная release-подпись не предоставлена.

Неизвестные системы обувных размеров остаются в отдельном каталоге с явным
согласием. Старые фиды не переимпортируются с новой датой наличия. Свежесть
рабочего ассортимента и полная первая сессия на нём требуют отдельной проверки.
