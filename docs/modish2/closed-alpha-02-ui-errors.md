# 0.2 — честные обещания и пользовательские ошибки

Работа 14–15 октября 2026, только локальная ветка `codex/closed-alpha-readiness`.
Production, текущий APK и рабочие данные не менялись.

## Изменения

- Экран Plus заменён сообщением о недоступности дополнительных возможностей.
  Убраны цена, оформление подписки, billing status и обещания функций.
  Возврат работает и при обычном переходе, и при прямом открытии route:
  текущая стадия аккаунта/онбординга сохраняется.
- `ApiClient.formatError` делегирует единому безопасному formatter. Он выбирает
  собственный русский текст по типу сбоя, HTTP status и контексту запроса.
  Только точные известные бизнес-ответы переводятся через закрытый словарь.
  Произвольные `detail`, validation arrays, HTML, `Dio.message`, inner exception
  и `Object.toString()` не попадают в интерфейс. Для ошибок есть следующий шаг.
- Локальные ошибки доступности сервиса и записи сессии имеют типизированные
  причины. Вход больше не предлагает открывать технический адрес сервера;
  timeout при запуске не раскрывает имена внутренних запросов.
- Сообщения backend о квоте анализа/подбора больше не предлагают оплату.
  Проверки квот, reservation и доступности функций не изменены.
- Style Swipe говорит о завершении настройки вкуса, а не гарантирует образы.
  Ошибки Intent сохраняют конкретное действие: изменить пожелания, обновить
  результат или создать новый запрос.
- Детали образа различают подтверждённое сохранение и последующую загрузку
  списков. Сбой GET после успешного POST/DELETE не выдаётся за сбой изменения.
  Кнопка отражает результат; повторный запрос заблокирован во время ожидания.
  Завершение удаления не закрывает товар, открытый поверх образа.

## Приёмка

- Полный изолированный backend suite: **472 теста**, 70.652 секунды, зелёный.
- Финальный целевой Flutter-набор: **44 теста**, зелёный — ошибки, Plus,
  сохранение образов, жизненный цикл сессии и shopping intent.
- Финальный полный Flutter suite: **218 тестов**, зелёный (01:00 по runner).
- Финальный `flutter analyze --no-pub`: **No issues found**, 3.4 секунды.
- Текстовый аудит видимых ошибок: feed, onboarding, auth, profile, saved,
  outfits, search, discovery, shopping task. Неизвестные ответы не обходят formatter.
  Визуально проверены состояния ошибки ленты и запроса на узком экране с
  увеличенным текстом; существующий аудит экранов также создал локальные PNG.
- Поиск в `lib` не находит цену подписки/оформление/оплату/обещание трёх комплектов.

Первый полный Flutter-прогон обнаружил два устаревших ожидания английской
диагностики и два зависающих старых preview harness. Ожидания исправлены с
сохранением проверок сессии. Зависание локализовано в чтении FeedHistory через
платформенное хранилище в fake-clock окружении до первого снимка. В двух harness
добавлены явный mock хранилища, подготовка в real-clock, шрифты проекта,
ограниченные ожидания, очистка и запрет незамоканного HTTP. Оба проходят отдельно
и в полном наборе. Изменять производственную загрузку картинок не потребовалось.

Финальный локальный аудит создал **234 снимка**, 0 ошибок Flutter framework.
Это диагностические fixture-состояния, а не проверка реального телефона или
качества каталога. Результаты — `.tmp/alpha02-full-ui`, дополнительные превью —
`.tmp/alpha02-preview6` и `preview7`. Исторические снимки предыдущих сборок
восстановлены и не включаются в этот кодовый срез.

Это приёмка блока 0.2, а не готовность всей закрытой альфы. Общий DoD открыт.
