# Modish 1.0.0, build 7 — 16 сентября 2026

Сервер обновлён 16.09.2026 в 22:15 МСК. Подтверждение: `release7_deployment_record.json`.

## Изменения

- Убраны подсказка о свайпах в ленте, бейдж «Для вас» и текст о комиссии в карточке товара.
- Обновление образов учитывает пять последних подборок каждого сценария и текущие сохранённые образы. Сначала выбираются ещё не использованные вещи; при дефиците допустимо повторить одну вещь, если как минимум две части образа отличаются. Проверка использует идентичность товара, а не только ID предложения.
- Одновременные запросы обновления одного пользователя последовательно учитывают историю друг друга. Если новых сочетаний нет, предыдущая подборка остаётся, а приложение показывает соответствующее сообщение.
- Кнопка обновления во вкладке «Все» обновляет daily, office и evening.
- «Сохранённое»: две вкладки «Вещи» и «Образы» со счётчиками, читаемые строки товаров, меню удаления, все части комплекта в сохранённых образах. Пустое состояние относится только к выбранной вкладке. Удаление и сохранение не перезагружают ленту.
- Повторный анализ из профиля показывает только выбор нового фото. Убраны дублирующиеся параметры и «В ленту без фото». Отмена возвращает в профиль без сетевого запроса; поздний ответ анализа не открывает ленту после отмены.
