# 2.3 — обувные системы и внешнее подтверждение фидов

18 октября 2026. Пункт не объявлен полностью закрытым.

## Что уже поддерживается

Общий size resolver принимает явно указанные EU/RU/UK/US и отдельный обувной
размер пользователя. Проверяет точное значение в той же системе и наличие
варианта; конфликт единиц и неизвестная система не дают персонального допуска.
Проверки resolver/evidence, Intent и матрица 2.2 покрывают эти ограничения.

Неподписанное число не превращается в EU/RU по диапазону, стране бренда или
похожей таблице. Такие вещи доступны только в отдельном каталоге с пометкой
размера и явным согласием из 2.1, не в персональной ленте и образах.

## Ограниченная повторная проверка публичных источников

- [CAPRICE Size Guide](https://capriceshoes.com/en-FI/service/size-guide)
  доступен через текстовый web-инструмент: таблица явно разделяет длину стопы,
  EU и UK, например 24,4 см / EU38 / UK5. Сам справочник называет значения
  усреднёнными. Он не описывает экспортное поле Shopping Live и offer/variant ID.
  Вывод: справочник производителя сам по себе не подтверждает систему поля фида.
- [BAON, таблица размеров](https://baon.ru/index/sizes/) в этой проверке
  вернула через текстовый инструмент только оболочку страницы. Новая подпись
  экспортного поля не получена; это не утверждение об отсутствии её на всём сайте.
- [Shopping Live, CAPRICE195449](https://www.shoppinglive.ru/p/krossovki-iz-oleney-kozhi-na-podkladke-iz-iskusstvennogo-meh-195449)
  не вернул читаемого содержимого. Наблюдение 9 октября о модельной стельке
  остаётся историческим, не выдаётся за повторное подтверждение сегодня.
- [Admitad: Product Feeds](https://academy.admitad.com/what-are-product-feeds-and-how-publishers-can-benefit-from-it/)
  объясняет TXT/CSV/XML и общие поля товара, но не определяет систему
  `param_размер` конкретных BAON/Shopping Live вариантов.

Фиды не скачивались, рабочая БД не изменялась, сообщения магазинам не отправлялись.
Предыдущие сохранённые доказательства и их границы описаны в
[исследовании 9 октября](official-size-contract-research-20261009.md).

## Что нужно получить

Нужна проверяемая цепочка: магазин/бренд/категория → экспортное поле → система
размера → конкретный вариант → свежее наличие. Подготовленный
[запрос владельцам фидов](merchant-size-contract-request.md) перечисляет нужные
поля и исключения. Общая таблица производителя без такой связи недостаточна.

## Решение о порядке работ

18 октября пользователь явно выбрал: «Продолжить остальные пункты;
неизвестные размеры оставить только в отдельном каталоге».
Поэтому подтверждение основных обувных фидов остаётся внешней зависимостью,
а работа продолжается с 3.1. Это разрешение изменить последовательность,
не ослабление size-gate и не разрешение production deployment.
