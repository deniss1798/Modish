# 2.2 — доступные по бюджету полные образы

Локальный срез 18 октября 2026. Только код и изолированные каталоги.

## Причина пустых подборок

В воспроизведённом каталоге есть полный комплект за 5 001 ₽ при бюджете
6 000 ₽. Однако десять более дорогих вещей с высоким рейтингом в каждом слоте
вытесняли доступные альтернативы. Обычный/WOW engine возвращал пустую подборку;
Intent на тех же данных уже сохранял дешёвый резерв и находил образы.

## Исправление

Для образов сохраняется небольшой ценовой резерв после всех обязательных
проверок. До отсечения категории в 50 SKU сохраняются три доступные по цене
альтернативы. До композиции доходят максимум десять кандидатов роли:
семь лучших по рейтингу плюс три дешёвых; пересечения заполняются следующими
рейтинговыми кандидатами. Обработка цен использует Decimal.

Небольшой общий selector не обращается к БД и не решает вопросы допуска.
Оценки финалистов сохраняются вместе с ними, чтобы не разбирать ранних
победителей повторно после вытеснения из ограниченного scorer cache.
Legacy путь также собирает ценовой резерв по каждой роли, даже если обычная
лента уже заполнила её дорогими вещами. Данные читаются порциями с соблюдением
общего времени ранжирования; комбинации остаются ограниченными 10³/10².

Размер, система размера, наличие варианта, SourceRule, сценарий, совместимость,
исключённые идентичности, ротация и бюджет всего комплекта сохраняются.
Резерв используется только в сборке образов. Порядок обычной ленты и Style
Swipe по умолчанию не меняется. Snapshot → read-only rank → короткая публикация
остаётся прежним; новые запросы под блокировкой пользователя не добавлены.

## Границы

Это исправление ограниченного отбора кандидатов, а не исчерпывающий поиск
всех комбинаций каталога. Три самых дешёвых варианта могут оказаться
несовместимыми; неподтверждённые размеры не становятся подтверждёнными.
Синтетическая матрица показывает работоспособность на известных SKU,
но не достаточность наличия и размерных данных в рабочих магазинах.

## Независимая проверка

Матрица содержит XS/S/M/L/XL/XXL, RU42/RU46 и два профиля с разными размерами
и системами верха/низа. Обувь EU36–41; бюджеты 4 000 / 10 000 / 25 000 ₽.
Каждый профиль проходит реальные HTTP preferences → колода не менее15 вещей →
15 сохранённых like → WOW → обычные образы → Intent. Оба шаблона проверены
непустыми: верх + низ + обувь и платье + обувь. Oracle — независимый реестр
заранее подписанных SKU, размеров, систем, цен и наблюдений наличия.

Четыре отрицательных сценария дают честный пустой результат во всех трёх
путях: неизвестная система обуви, неверный точный размер, отсутствие всего
низа и превышение суммы комплекта при допустимой цене каждой отдельной вещи.

Отдельные regressions проверяют более50 дорогих кандидатов каждой роли,
7+3/fill при пересечении резервов, legacy-резерв при уже заполненных слотах,
6001 более новый неверный обувной размер перед подходящим, исторические aliases
до отсечения, дешёвые невалидные товары/офисную обувь и SELECT-only prepare.
Поток более512 SKU оценивает каждую вещь один раз и использует менее45 SQL
запросов, а не запрос на каждую вещь. Это структурная проверка, не production p95.
