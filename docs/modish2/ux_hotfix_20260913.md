# Исправления интерфейса и подборок — 13.09.2026

Применено на production 13.09.2026 в 08:04 UTC (11:04 МСК). [Запись deployment](outfit_hotfix_deployment_record.json). Health и публичный каталог отвечают HTTP 200; закрытая лента без авторизации — HTTP 401. Контейнеры PostgreSQL и Redis сохранены, временная тестовая база удалена.

Пакет относится к шести замечаниям пользователя со скриншотами. Он не закрывает весь план T00–T12 из исходного документа.

## Что изменено

- `MobileViewport` заполняет экран. Содержимое главных вкладок находится под системной строкой состояния.
- Первая подборка использует карточки с фотографиями и переходом к составу образа; названия сценариев переведены. Для пустого результата есть объяснение и переход в ленту.
- Из образов, подсказок поиска и фильтров убраны аксессуары. Поддержаны два состава: верх + низ + обувь либо платье/комплект + обувь. Фотографии в образах показываются целиком.
- Варианты одного товара объединяются по source/group_id, source/vendor_code и URL изображения. В новых образах одной генерации вещи не используются повторно; недостаток вариантов не дополняется почти одинаковыми комбинациями.
- Добавлены ограничения на бельё, купальные и домашние вещи, детские товары, спортивную экипировку и несоответствие сценарию. Куртки и кардиганы не выступают единственным верхом. Уточнены цветовые и сезонные ограничения.
- Явные сведения о поле из названия и исходных категорий проверяются даже при ошибочной метке `unisex`. Неоднозначные товары не подставляются в образ автоматически; для обуви предусмотрены ограниченные правила по типу модели.
- Старые неполные, неподходящие и повторяющиеся образы фильтруются при чтении. Сохранённые строки базы не удаляются.
- Нулевая выдача или ошибка v2 больше не запускает старый подбор, который обходил ограничения. Явный внутренний вызов legacy с `use_v2=False` сохранён для совместимости; публичные маршруты используют v2.
- Свайп сразу удаляет товар и его варианты из очереди. Поздний ответ обновления не возвращает просмотренное; параллельное повторное действие по одной карточке подавляется. Открытие товара не перестраивает ленту. Убран второй скрытый запрос той же ленты и автоматические повторы изменяющих HTTP-запросов.
