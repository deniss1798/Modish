# Modish — локальная подготовка закрытой альфы

Работа по ТЗ от 13 октября, состояние на 19 октября 2026.
Полный поэтапный статус: [план и приёмка](closed-alpha-plan-20261014.md).

## Сделано в текущем продолжении

- 1.5: подтверждённые реакции сразу учитываются клиентом; каждая десятая
  обновляет оставшуюся очередь. Save replay и task-only причины не обучают
  повторно; телеметрия не блокирует действие. HTTP проверки доказывают
  изменение порядка неизменных кандидатов через Taste/User Twin.
- 2.1: каталог непроверенного размера не загружается до явного согласия.
  Входы из профиля, поиска, ленты и онбординга проходят общий экран.
- 2.2: ограниченный ценовой резерв не даёт дорогим рейтинговым вещам
  вытеснить доступные полные комплекты. Реальный HTTP путь проверен
  на десяти независимо размеченных синтетических профилях.
- 3.1: у первых 20 карточек есть безопасный срез текущих причин отказа;
  повторные события и произвольная телеметрия не увеличивают метрики.
- 3.2: опциональный белый список закрывает регистрацию, вход, старые JWT,
  refresh и прежние публичные входы каталога. По умолчанию выключен.
- 3.3: раздельные live/ready проверки и строгая клиентская готовность.
- Дополнительная [Android-приёмка](closed-alpha-34-device-journey.md):
  настоящий Flutter UI → локальный HTTP → новая синтетическая БД.
  Исправлена потеря возможностей каталога/подбора после первой сессии.
  Полный путь с 15 реакциями, WOW, лентой, сохранением, поиском и явным
  согласием на каталог прошёл на эмуляторе с трёхкнопочной навигацией за 39 с.
- [Заключительный срез](closed-alpha-35-final-local-checks.md): полный backend
  вместе со всеми 55 PG-сценариями, без пропусков; расширенный Android-путь
  с сохранением параметров и повторным открытием формы прошёл за 50 с.

Ранее принятые пункты 0.1–1.4 и их подробные ограничения сохранены в плане.
Изменения разбиты на локальные коммиты. Для Android-приёмки добавлен стандартный
dev-only `integration_test` Flutter SDK; runtime-зависимости не менялись.

## Что не подтверждено локальными тестами

Пункт 2.3 остаётся [внешней зависимостью](closed-alpha-23-footwear-dependency.md).
Пользователь разрешил продолжить остальные работы; неподписанные обувные
размеры остаются только в отдельном каталоге, без персонального допуска.

Синтетические SKU доказывают корректность логики, но не свежесть рабочего
ассортимента, доступность размера в checkout и скорость на физическом телефоне.
Готовность всей реальной первой сессии на рабочем каталоге не объявляется
доказанной одним зелёным набором тестов.

В рамках этого ТЗ сервер, рабочая БД и GitHub не обновлялись. Пользовательский
APK не публиковался; локальный debug APK собирался только для интеграционного теста.
Реальные участники не добавлялись и приглашения не рассылались.
