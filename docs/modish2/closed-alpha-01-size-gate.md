# Альфа0.1: точный размер

14 октября 2026. Изменения локальные, production и APK build14 не менялись.

## Изменено

- Общая `evaluate_personal_size` проверяет подтверждённый размер конкретного
  слота, систему и точное доступное значение. Admission, legacy filters,
  MIE и пояснения используют один контракт; неизвестный профиль не становится M.
- MIE возвращает hard reject и нулевой FitScore до мягкого скоринга при отсутствии
  точного размера. Положительный вкус/популярность не дают допуск; причина
  «Есть ваш размер» формируется только после подтверждения.
- Строковые legacy sizes читаются как один токен. `XL` не превращается в X/L,
  `XS` — в X/S. Словарь ключей и некорректная структура stock evidence не служат
  доказательством наличия. Правильные одиночные M/XL, списки, tuple и прежний
  iterator path сохранены; не добавлены межсистемные конверсии.
- Legacy `_bucket_products` закрывает обход аварийной raw-загрузки: normal,
  refill и emergency проходят `evaluate_eligibility`, включая unknown Fit.
- Прямые пояснения activation/Intent не утверждают наличие при неизвестном
  размере; сериализация не маркирует неподтверждённый матч как confirmed.
- Аудит feed category fallback/refill, V2, WOW, Intent/replacement/cached GET и
  complements подтвердил hard admission перед выдачей. Coarse SQL/явный фильтр
  размера не заменяет exact gate. Исправлен старый комментарий об ослаблении размера.

## Проверка

| Проверка | Результат |
| --- | --- |
| Полный изолированный backend suite | 471 тест, 60,413 с, OK; `.env` и внешние интеграции выключены |
| Flutter analyze | Без замечаний, 41,2 с; Flutter-код в этом блоке не менялся |
| MIE/admission regression | XS–XXL, S/XL, L/M, RU46/RU48, одинаковые токены разных систем, unknown/unconfirmed, individual shoe slot, отсутствующий per-size stock, compound и scalar containers |
| Legacy emergency | 11 новых тестов, принудительно пустой strict retrieval и реально выполненная raw-загрузка; сохранены положительные полные комплекты M/EU38 и RU46/EU38 |
| Полная персональная сессия на тестовом каталоге | 3 профиля: S против XL, L против M, RU46 против RU48; по42 SKU, включая24 правильных и18 неправильных |

Сквозные тесты проверяют Style Swipe с15–20 непустыми карточками,15 реальных
тестовых лайков, непустые полные WOW, персональную ленту и item Intent.
Каждый возвращённый SKU входит в независимый заранее известный positive-set;
ни один — в negative-set. Оракул не вызывает проверяемый size-gate.
Устаревшие общие `clothing_size=M` и session shoe39 не заменяют подтверждённые слоты.

Критерии0.1 выполнены на синтетическом тестовом каталоге; реальный production
каталог и реальные люди в рамках этого блока не проверялись. Эти тесты не доказывают
размерные сетки магазинов, достаточность SKU или готовность всего ТЗ к инвайтам.
К следующим блокам можно переходить; общий Definition of Done остаётся открытым.
