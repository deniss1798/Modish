# Проверка обувных размеров Shopping Live — 6 октября 2026

Прочитаны публичная карточка [Caprice 195449](https://www.shoppinglive.ru/p/krossovki-iz-oleney-kozhi-na-podkladke-iz-iskusstvennogo-meh-195449), её вкладка «Характеристики», инструкция «Таблица размеров» и [общая справка](https://www.shoppinglive.ru/voprosi-i-otveti). Вход и покупка не выполнялись.

У карточки выбираются значения 36–42. В характеристиках есть длина и ширина стельки по этим значениям, но система RU/EU не обозначена. Инструкция направляет к замерам конкретной модели. Общая справка не содержит подтверждения единой размерной системы обуви.

Например, для маркировки 38 указаны стелька 24,7 см и ширина 8 см. Это замеры конкретной модели, не длина стопы и не доказательство EU 38. Их нельзя переносить на другой артикул или на все 9121 обувных SKU из исторического тестового снимка.

**Решение:** не вводить глобальное правило Shopping Live → EU, не ослаблять `confirmed_product_size`. Числовые значения с неизвестной системой остаются неизвестными. Закрыть пробел можно явным полем системы в фиде, подтверждённым контрактом источника с точной областью действия либо отдельной модельной таблицей сопоставления с происхождением данных. Последний путь потребует пользовательских мерок и не равнозначен автоматическому пересчёту EU/RU.

Эта проверка завершает ранее остановленное чтение характеристик после CAPTCHA. Проверка на сайте не подтверждает наличие товара или свежесть сохранённого сентябрьского фида. Перед следующей проверкой десяти профилей нужен новый снимок остатков.
