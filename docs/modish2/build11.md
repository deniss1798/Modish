# Modish 1.0.0 build 11 — шесть замечаний по приложению

Дата: 22 сентября 2026. API: `https://modish.org.ru`.

## Что изменено

1. **«С чем носить».** Для верхней одежды добавлена проверка обуви по названию вещи, сезону и явным параметрам утеплителя. Куртки не дополняются открытой обувью; пуховые/утеплённые куртки также не дополняются лёгкими туфлями, балетками и лоферами. Кардиган не приравнивается к зимней куртке: закрытая лёгкая обувь для него остаётся допустимой. Проверки действуют в обоих направлениях пары и при подборе дополнений из активационного каталога. Рекомендация остаётся основанной на данных товара, а не на распознавании его фотографии.
2. **Кнопка сохранения.** В «Моих параметрах» кнопка вынесена в нижнюю панель с SafeArea. Отступ учитывает системную навигацию Android. Заодно исправлено чтение сохранённых роста и веса: API возвращает `height`/`weight`, а экран ранее ожидал только `height_cm`/`weight_kg`.
3. **Стартовый экран.** Удалены русские рекламные заголовок и подзаголовок. Сохранены изображение с MODISH / YOUR STYLE SMARTER, вход, регистрация и правовой текст.
4. **Поиск.** Исправлена отправка текста как фильтра бренда. Новый `GET /products?q=...` ищет по названию, бренду, категории и цвету до пагинации, сохраняя проверку пола и пригодности товара. Несколько слов уточняют запрос вместе; поддержаны частые формы названий одежды и цветов. Например, «чёрные брюки», «BAON», «куртка BAON». Запрос «джинсы» не совпадает с курткой только из-за слова «джинсовая». В UI добавлены поиск при вводе, очистка, загрузка следующих результатов, отдельные состояния отсутствия результатов и ошибки сети, защита от запоздавших ответов. Фиктивные «Недавние» и «Популярное» заменены честными примерами запросов. Поиск работает по каталогу, а не только по текущей пачке ленты; бюджет и размер не заявлены как фильтры этого экрана.
5. **Заголовки вкладок.** Крупный знак убран из ленты; теперь там заголовок «Лента», оформленный как «Образы», «Сохранённое» и «Профиль». Логотип сохранён на стартовом экране.
6. **Предпочтения.** Старые Chip не имели обработчика нажатия, но выглядели как кнопки. Они заменены текстовой сводкой с источниками: выбор при знакомстве, положительные веса стилей/цветов по реакциям и параметры подборки. Убраны запасные «Минимализм / Casual» и выдача общей палитры анализа за личные предпочтения. Цвета переведены на русский, неизвестные размер/бюджет не подменяются значениями по умолчанию. При открытии профиля данные вкуса обновляются.
